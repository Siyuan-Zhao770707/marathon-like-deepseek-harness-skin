# 2.4.9 — 工作区管理、独立配色与统一文字朝向

新版色条补回工作区管理入口，并支持给每个工作区单独选颜色。中文、英文和混排名称统一侧转 90°，从下往上读。

## 更新内容

- 色条编号下方的「…」打开 Harness 原生菜单，可重命名或删除工作区。删除保留原生确认框；移除工作区后，文件夹与会话记录仍保留，会话进入「未分组」。
- 悬浮会话卡片底部新增工作区颜色：可使用选色器、输入六位 HEX 色值或恢复默认。颜色按工作区在本机保存，刷新后恢复，顶部当前工作区同步更新；自定义深浅颜色自动选用清楚的文字色。
- 中文、英文和中英混排采用相同朝向，修复中文倒置与方向不一致的问题。
- 修复工作区菜单和悬浮卡片互相干扰的问题；普通点击不再被误判为拖拽，避免编号意外变化。
- 保留经典工作区样式、现有默认识别色与外观偏好。

感谢 [shanshanyeah](https://github.com/shanshanyeah) 在 [#2](https://github.com/yasneg616/marathon-like-deepseek-harness-skin/issues/2) 中的反馈与配色建议。

## 直接安装或升级

无需构建源码，也无需为皮肤安装 Node.js。在 Harness「插件 → 添加插件」的**包名或地址**输入框粘贴完整地址，安装后启用：

```text
https://github.com/yasneg616/marathon-like-deepseek-harness-skin/releases/download/v2.4.9/dsh-industrial-acid-skin-2.4.9.tgz
```

也可先下载 `.tgz`，再输入下载文件的本机绝对路径。仅输入文件名会发起 npm 查询，请使用完整 URL 或绝对路径。已有用户使用相同插件包名升级；如 Harness 提示需要重启，再重启客户端。

## 验证与兼容

构建、语法检查与 **65 项自动测试**通过。在本机 Windows Harness 中验证了原生重命名、删除确认与取消、独立改色、恢复默认、刷新保存、明暗配色、520×600 和 800×600 窗口，以及经典与新版样式切换。删除流程使用临时工作区，原有工作区和外观偏好均保留；验证未发送会话消息。

文字方向另通过 **12 项浏览器检查**，使用实际皮肤 CSS 在隔离页面验证中文、英文与混排同向、从下往上读，且不与编号重叠。运行包从最终提交的独立源码导出构建，预编译客户端与仓库一致。

兼容声明保持为 DSH `>=0.2.0-rc.2 <0.2.2-0`；声明范围中的其他版本和平台不等同于全部完成本轮实测。安装、构建与回退详见仓库的 `docs/INSTALL.md`。
