# 2.4.6 — 新版色条、经典布局与 MORE 转场

工作区加入 113px 的双列错位色条，每项保留自己的编号和识别色。悬停或键盘聚焦可展开会话卡片，卡片随明暗模式使用黑底白字或白底深字。

- 在「调色盘 → 工作区样式」即时切换新版色条和经典工作区，刷新或重启后保留选择。修复经典单列表切回新版色条无效的问题，并恢复旧的冲突状态。
- 经典侧栏的四个按钮改为紧凑 2×2，新会话保持高亮，给工作区列表留出更多高度。
- MORE 条纹与更多入口跟随调色盘，展开和收起接入四色遮罩，支持快速反向操作和 Escape 收起；修复更多菜单的黑色遮挡。
- 恢复新版 Harness 消息输入框的矩形边框、切角、信号灯和聚焦反馈，并保留 2.4.3 的消息气泡可读性修复。
- 补齐 rc.3 产出文件与变更摘要卡片的明暗配色，修复浅色模式黑底黑字；选中工作区的白色箭头增加深色包边。
- 可选 Windows 标题栏适配器新增哈希核验的 DSH 0.2.1-rc.3 支持，可使用右上角竖排的最小化、最大化／还原与关闭按钮。
- README 新增三组 1× GIF 和新版截图；展示内容均为虚构数据。

## 安装

在 Harness「插件 → 添加插件」的**包名或地址**输入框粘贴完整地址，安装后启用：

```text
https://github.com/yasneg616/marathon-like-deepseek-harness-skin/releases/download/v2.4.6/dsh-industrial-acid-skin-2.4.6.tgz
```

也可下载 `.tgz` 后输入本机绝对路径。仅输入文件名会触发 npm 查询。现有安装保留包名 `dsh-industrial-acid-skin`，可继续升级。

## 文件

| 文件 | 用途 |
| --- | --- |
| `dsh-industrial-acid-skin-2.4.6.tgz` | Harness 插件运行包，日常升级使用此文件 |
| `dsh-industrial-caption-adapter-2.4.6.zip` | 可选 Windows 窗口按钮适配器，解压后按内附 README 操作 |
| `SHA256SUMS.txt` | 上述两个文件的 SHA256 校验值 |

适配器需 Node.js 22+，只接受已核对哈希的 0.2.0-rc.2、0.2.1-rc.2 和 0.2.1-rc.3；安装前完全退出 Harness，写入前自动备份，支持恢复。插件本身无需修改应用 archive。
